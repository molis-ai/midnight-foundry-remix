# 午夜造物局 · 一起改

**AI 做了第一版。下一版，换你来。**

我在做一个叫「午夜造物局」的栏目：睡前向 GPT-6 许愿，早上打开它做的小作品，再把我试玩后的判断交给它，做出一个 Pro 版。

现在，我也想把第一版交到你手里。你会想改哪里？一句话、一道题、一个结局，都可以。Pro 是修改版的名字，谁更好玩，玩过再说。

## 从这件作品开始

### 000 · 人类验证局

追一个会逃跑的勾选框，忍住一个写着「千万别按」的按钮，最后领到一张不太正经的「人类证明」。六个小动作，约一分钟。

## 不知道改什么？先动一小处

- 把证书上的一句话，换成只有你和朋友才懂的梗。
- 把一道题改得更荒诞，但让人一看就知道怎么玩。
- 给结果加一个你自己的结尾，让人愿意截图发给某个人。

可以自己写，也可以让你习惯的 AI 帮忙。想做更大的改版当然也欢迎，只改一句话也值得交出来。

## 改完怎么加入

1. **保留自己的版本。** Fork 这个仓库，在自己的副本里修改。[开始指南](docs/开始改一处.md)会帮你把原版复制到独立目录。
2. **让别人看见变化。** 提交一条作品 Issue，写清改了什么，附源码，以及可玩链接或演示录屏。暂时不会部署也可以交。
3. **一起看具体的好点子。** 我会在每周回顾时挑选有意思的作品，按你同意的方式署名、链接，并说清楚哪个小改动打动了我。没有固定名额，也不保证每件都会入选。

你的代码留在你的仓库；这里通过作品卡片链接过去。你也可以更新原投稿，告诉大家后续又改了什么。

每天的作品会陆续开放，每周集中玩一个主挑战。作者原版与 Pro 的 A/B/C 投票继续保留；社区版本另开作品回顾，让不同方向的灵感都有被看见的机会。

## 这是怎样一场实验

我想看看 AI 能独立做出什么，也想看看不同的人会把同一个起点带向哪里。一个更好笑的措辞，一个更顺手的动作，甚至决定什么都不加，都可能是人的判断。

这里是公开共创入口，包含已开放的原版、指南和社区作品索引。栏目制作档案另行保存；未交付版本不会冒充成原版开放。

目前开放人类验证局 v0.1 源码和[在线试玩](https://molis-ai.github.io/midnight-foundry-remix/000-human-verification-bureau/original/)。栏目尚未正式发布，也还没有首批社区投稿。
