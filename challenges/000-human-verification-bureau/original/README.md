# 人类验证局

**请证明，你不是 AI。**

一个约一分钟的中文荒诞互动小游戏。六道不太正经的验证，最后发给玩家一张有点问题的「人类证明」。这是一个完整的本地可玩版本，尚未公开部署，也没有真实流量数据。

## 开始玩

```bash
cd challenges/000-human-verification-bureau/original
npm ci
npm run dev
```

打开 [本地游戏](http://127.0.0.1:4178)。需要 Node.js 22.12+；本次使用 Node.js 25.9.0。

```bash
npm run build
npm run preview
```

开发与预览共用 4178 端口，不要同时启动。端口被占用会明确报错；停止本项目已启动的服务后再切换，不会自动挤掉其他服务。

## 这一分钟里会发生什么

1. 追一个会逃跑的「我不是机器人」勾选框；也可以拒绝自证。
2. 从六件生活物品里，选择你想留到明天再做的事。
3. 摆正一幅有点歪的肖像；也可以允许它歪着。
4. 面对一个写着「千万别按」的按钮，坚持五秒。
5. 用自己的感觉估计三秒钟，也可以拒绝被考核。
6. 接受一份允许自己不完美的「人类使用条款」。

根据本局操作，得到五种趣味称号之一。结果页展示六条实际操作证据，可以下载 **1080 × 1440 PNG**，也可以复制同题挑战链接。图片生成完全在浏览器本地完成。

同题链接只携带种子和五种称号之一，朋友打开后看到相同的物品顺序和画框起始角度。没有上传作答、账号、数据库、分析埋点、真实身份识别或心理测评。纯属娱乐。

## 为什么这样做

人们可以从熟悉的「验证码」直接进入，不用先理解玩法。会躲的勾选框和不能按的按钮提供录屏里的反应点，六条真实操作记录让结果图更像「这就是我」，同题链接让朋友接着玩。结尾从捉弄转向接纳，让体验留下一点温度。

这些是产品假设，**不等于已经证明能带来流量**。第一步是拿可玩的成品给真实的人，观察他们能否自主完成、是否主动分享，避免提前增加排行榜、注册或复杂增长系统。

最小性取舍：当前必须是六题完整闭环、结果可追溯、下载可用、分享有入口；账号、付费、模型接口、排行榜、跨端存档、后台仪表盘均延后。

视觉使用冰蓝背景 `#e8f0f5`、深蓝字色 `#17365a`、纸白 `#fffefa`、盖章橙 `#e7653e`、嫩绿 `#d9ec8a`。主体是一台给不标准的小人发证的扫描机。字形使用本地中文黑体系统字体。角色、物品、扫描机都是项目内的 SVG/CSS，没有外链字体或图片请求。

## 文件与运行边界

- `src/main.js`：六题交互、页面、输入清理和本地分享。
- `src/logic.js`：同题种子、五种称号规则、操作证据。
- `src/art.js`：原创 SVG 角色与生活物品。
- `src/poster.js`：Canvas 结果图生成与下载。
- `src/style.css`：桌面与窄屏布局、动作反馈、减少动态效果模式。
- `tests/`：规则验证与浏览器完整旅程。

声音默认关闭，由用户开启；不依赖外部音频。长按支持触屏、鼠标与键盘，失焦 / 取消 / 切后台会清理本题按压；禁按题切后台时暂停倒计时。剪贴板不可用时会展示可手动复制的链接。

## 验证

```bash
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

浏览器测试对最终 `dist/` 产物运行，覆盖桌面与移动端模拟、完整正常 / 反骨路径、PNG 下载、同题链接、重玩、计时取消恢复及 320px 窄屏。默认截图存到 `work/acceptance`，可以用 `HUMAN_BUREAU_ARTIFACT_DIR` 指定产物目录。

工程验证与浏览器实操只是当前证据。**真机触屏手感、iOS 保存行为、持续使用、VoiceOver 连续听感、用户验收与传播效果仍待验证。**

## 公开上线

`dist/` 可交给静态托管服务，以站点根路径发布，不需要服务器或密钥。当前未执行上传、创建远程仓库、绑定域名或公开发布。

公开 HTTPS 地址上线后，同题链接会自动使用实际域名。本机预览会明确提醒链接仅供本机使用。发布前应在最终 HTTPS 域名和至少一台真实手机上验证主流程、下载、分享，再进行真实传播尝试。

技术参考：[Vite 官方文档](https://vite.dev/guide/)、[MDN Clipboard API](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard_API)。
