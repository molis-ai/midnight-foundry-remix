# 000 · 人类验证局：这张证，你想怎么发？

**AI 做了一台给人类发证的机器。你可以让它更离谱，也可以让它更温柔。**

六个荒诞的小动作，换一张带着实际操作记录的「人类证明」。这是 GPT-6 在收到作者追加意见前交付的 v0.1；后续作者修改版不混入这个起点。

## 先玩，再改一处

1. **玩原版**：[本地运行](../../docs/开始改一处.md)。公开网页版尚未上线。
2. **开始改**：[AI 提示词](../../prompts/帮我改一处.md) · [直接看源码](original/)。
3. **交出你的版本**：[作品投稿](https://github.com/molis-ai/midnight-foundry-remix/issues/new?template=remix.yml) · [只有灵感](https://github.com/molis-ai/midnight-foundry-remix/issues/new?template=idea.yml)。
4. **看看其他方向**：[社区作品墙](../../showcase/README.md)。

## 三张灵感纸条

- **改一句话**：让证书像你的朋友、老板或周一早上的自己写的。可以从 `src/logic.js` 的 PROFILES 开始。
- **改一道题**：保留一个简单动作，换成你观察到的成年人小习惯。从 `src/main.js` 开始，注意同步操作证据。
- **改一个结尾**：拿证之后，让人愿意把它发给某个人。从 `src/poster.js` 和结果页开始，检查导出的图。

也欢迎完全不同的点子。投稿写清「我改了什么」和「我想让谁在什么瞬间笑一下」，不用写长篇产品说明。

## 这一期怎样回顾

这件作品先作为共创试点，尚未启动正式征集时限。正式帖子发布时再公布回顾时间，不追溯计算截止日。

回顾会关注出乎意料的方向、让人想分享的瞬间，以及很小却有效的改动。入选会注明作者、源码和演示入口；是否改得比原版好，可以各有判断。
