# 大家把它改成了什么

这里会留下从同一个原版长出来的不同方向。一句好笑的话、一个更舒服的动作，都值得被看见。

**目前还没有收录的社区作品。**

→ [交出你的版本](https://github.com/molis-ai/midnight-foundry-remix/issues/new?template=remix.yml)
→ [看看已提交的作品](https://github.com/molis-ai/midnight-foundry-remix/issues?q=is%3Aissue%20label%3Aremix)
→ [灵感池](https://github.com/molis-ai/midnight-foundry-remix/issues?q=is%3Aissue%20label%3Aidea)

作品收录时会写明：作品名、作者及其认可的链接、出发挑战、改动亮点、源码、可玩地址或演示、检查日期、原投稿。仅有录屏的标记「演示」，已检查到可用入口的标记「可玩」；想法留在灵感池。

入选不是排行榜。作者原版与 Pro 的版本投票在栏目对应内容中进行，社区作品按各自方向讨论。
