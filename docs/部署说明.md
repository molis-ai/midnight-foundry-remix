# 让朋友打开你的版本

不会部署也可以先交录屏。部署不是投稿前置条件。

人类验证局是纯静态前端，不需要服务器、数据库或 API 密钥。在你已有的静态托管服务中新建自己的项目，使用以下配置：

| 配置 | 值 |
|---|---|
| 源码仓库 | 你自己的 Fork |
| 根目录 | remixes/my-human-bureau（或你实际的作品目录） |
| 安装 | npm ci |
| 构建 | npm run build |
| 输出 | dist |
| Node | 22.12+ |
| 路径 | 独立站点根路径 `/` |

如果服务支持静态目录上传，可以先本地构建，再上传 `dist`。具体入口、额度和公开范围以所选服务的当前说明为准；这里没有配置一键部署，也不承诺免费额度。

原版默认站点根路径。发布到 `/仓库名/` 等子路径时，需要在你自己的副本中设置合适的 Vite base，并检查 favicon、资源和分享链接；记录这个部署适配，不修改冻结原版。参考 [Vite 部署文档](https://vite.dev/guide/static-deploy.html)。

拿到真实 HTTPS 地址后，打开最终网址，做完六题、保存 PNG、复制同题链接，在另一浏览器会话中打开并完成挑战。再用实际手机试一次。失败的步骤如实记录。localhost 和预览截图不能替代公开访问验证。

部署你自己的版本，保留原始来源及许可证；不要把私人笔记、密钥或不该公开的数据一起上传。填写投稿时写清对应源码提交，避免视频、页面和源码分别来自不同版本。
