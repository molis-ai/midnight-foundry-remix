# 从原版到你的版本

目标很小：先把人类验证局跑起来，再做一个你想让朋友看到的变化。

## 1. 拿到自己的副本

有 GitHub 账号：点仓库右上角 **Fork → Create fork**，在自己的仓库点 **Code** 复制克隆地址，再用你习惯的 Git 工具下载到电脑。Fork 和投稿需要登录 GitHub。

暂时不想处理 Git：点 **Code → Download ZIP**，解压后用 AI 编程工具打开这个文件夹，也可以先开始。以后再把自己的修改上传到自己的公开仓库。完整源码链接是作品投稿的一部分。

需要电脑和 Node.js 22.12 或以上版本。在仓库根目录的终端执行：

```bash
node scripts/start-remix.mjs
cd remixes/my-human-bureau
npm ci
npm run dev -- --port 4188
```

打开终端显示的 http://127.0.0.1:4188 。这是本机地址，其他人不能直接打开。4188 已占用时改为别的空闲端口，不要停止别人的服务。关闭本次服务用 Ctrl+C。

脚本只复制源码，不更改原版。再次执行会拒绝覆盖已有作品。想做第二份，可回到仓库根目录指定名字：

```bash
node scripts/start-remix.mjs 000-human-verification-bureau my-second-idea
```

## 2. 让 AI 改一处

把[这段提示词](../prompts/帮我改一处.md)交给 AI，补上你想改的地方。代码在 `remixes/my-human-bureau`；里面 README 是原版历史说明，当前路径和操作以本指南为准。

| 想改什么 | 先看哪个文件 | 注意什么 |
|---|---|---|
| 结果称号的一句话 | src/logic.js 的 PROFILES | 保留称号 ID，页面和证书共用这里的文字 |
| 某一题的交互或措辞 | src/main.js | 文案改了，对应按文字查找的浏览器测试也要更新 |
| 证书的结尾或排版 | src/poster.js | 真的保存一张 PNG，检查文字没有被裁掉 |

例如：把「规则读完了，但没说要听。」改成你自己的梗。这是小改动示例，不是社区投稿或官方 Pro。

## 3. 跑完再交

在自己的作品目录执行：

```bash
npm test
npm run build
npm run preview -- --port 4189
```

在 http://127.0.0.1:4189 玩完整六题，检查结果、保存证书、同题挑战和重玩。特别看看自己改的地方，记录不确定的问题。构建成功不代表手感已经好。

原版另附浏览器测试：`npx playwright install chromium` 后执行 `npm run test:e2e`。它会使用 4179 端口；占用时先查清来源，不抢占服务。测试里的设备是模拟，手机真机仍需另测。

## 4. 用链接或录屏交作品

有可玩地址最好；没有也可以录下从首页到结果的一段完整玩法，在投稿里上传视频或贴可访问的录屏链接。不要用截图轮播冒充操作视频。

想部署时看[部署说明](部署说明.md)。把源码推送到自己的公开 Fork，填写作品目录里的 `REMIX.md`，然后[提交作品](https://github.com/molis-ai/midnight-foundry-remix/issues/new?template=remix.yml)。源码最好链接到具体提交及作品目录，方便别人看到同一版。

不要求提 Pull Request，不要求先部署，更不要求胜过作者的 Pro。只有想法就走[灵感入口](https://github.com/molis-ai/midnight-foundry-remix/issues/new?template=idea.yml)。
